# --setup-env Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `--setup-env` and `--cleanup` flags to dtt, allowing tests to auto-create DingoFS filesystems before running.

**Architecture:** Single file change in `dingofs-testsuite-tool`. When `--setup-env <env>` is specified, dtt calls `test_env_setup.py` on the host to create fs + mount before starting the Docker container. The `test_env_setup.py` script internally calls `dtt config set testdir` so the config is updated automatically.

**Tech Stack:** Bash (dtt script), Python 3 (test_env_setup.py/env_cleanup.py, run on host)

### Task 2: Implement env setup execution

**Files:**
- Modify: `dingofs-testsuite-tool` (after `mount="${mount:-$config_testdir}"` line ~1142)

- [ ] **Step 1: Add env_setup execution before container run**

After `mount="${mount:-$config_testdir}"` and `output="${output:-$config_output}"` (line ~1143), insert the setup logic:

```bash
# --- setup-env: create filesystem and mount ---
local integration_test_dir
integration_test_dir=$(dirname "$0")/dingofs-integration-test

if [[ -n "$setup_env" ]]; then
    # Resolve env yaml path: custom dir first, then built-in
    local env_yaml=""
    if [[ -n "$config_custom" ]] && [[ -f "$config_custom/${setup_env}.yaml" ]]; then
        env_yaml="$config_custom/${setup_env}.yaml"
    elif [[ -f "$integration_test_dir/conf/env/${setup_env}.yaml" ]]; then
        env_yaml="$integration_test_dir/conf/env/${setup_env}.yaml"
    else
        echo "Error: env '${setup_env}' not found in /custom/ or conf/env/"
        return 1
    fi

    echo "Setting up environment: $setup_env"
    echo "  YAML: $env_yaml"

    pushd "$integration_test_dir" > /dev/null
    python3 tests/test_env_setup.py "$setup_env"
    local setup_exit=$?
    popd > /dev/null

    if [[ $setup_exit -ne 0 ]]; then
        echo "Error: env_setup failed (exit: $setup_exit)"
        return $setup_exit
    fi

    # test_env_setup.py internally ran: dtt config set testdir <mount_path>
    # Reload testdir from config
    mount=$(load_config testdir)
    echo "Test dir updated to: $mount"
fi
```

### Task 3: Implement cleanup after tests

**Files:**
- Modify: `dingofs-testsuite-tool` (after the docker run line, at the end of `run_testsuite()`)

- [ ] **Step 1: Find the docker run invocation and add cleanup after it**

Find the line `"${docker_cmd[@]}" "$image" "${entrypoint_cmd[@]}"` (around line ~1390) and wrap it with cleanup logic:

```bash
# Execute docker command with entrypoint
"${docker_cmd[@]}" "$image" "${entrypoint_cmd[@]}"
local test_exit=$?

# --- cleanup: unmount and delete filesystem ---
if [[ -n "$do_cleanup" ]] && [[ -n "$setup_env" ]]; then
    echo ""
    echo "Cleaning up environment: $setup_env"

    pushd "$integration_test_dir" > /dev/null
    python3 -c "
import sys
sys.path.insert(0, '.')
from src.config import env_cleanup
env_cleanup('$setup_env')
"
    local cleanup_exit=$?
    popd > /dev/null

    if [[ $cleanup_exit -ne 0 ]]; then
        echo "Warning: env_cleanup failed (exit: $cleanup_exit)"
    else
        echo "Environment cleanup complete."
    fi
fi

return $test_exit
```
