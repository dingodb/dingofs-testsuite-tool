### Task 2: Fix --add-host logic for multiple IPs
**File:** `dingofs-testsuite-tool`

The current code at lines 231 and 328 does:
```bash
local mds_ip="${mdsaddr%:*}"
```

This only extracts the IP from the **last** address. Need to extract unique IPs from all addresses.

Replace with:
```bash
# Extract unique IPs for --add-host (same IP with different ports only needs one entry)
local unique_ips=$(echo "$mdsaddr" | tr ',' '\n' | while read -r addr; do
    [[ -n "$addr" ]] && echo "${addr%:*}"
done | sort -u | tr '\n' ' ')

for ip in $unique_ips; do
    docker_cmd+=("--add-host" "mds:${ip}")
done
```

**Verify:** With `mdsaddr=172.30.14.126:6900,172.30.14.126:6901,172.30.14.126:6902`, only one `--add-host mds:172.30.14.126` is added

---

## Implementation Notes

- The mdsaddr value is stored as-is and passed to dingo CLI commands directly (dingo handles comma-separated addresses natively)
- For `--add-host`, we only need unique IPs since Docker host entries map hostname→IP, not hostname→IP:port
- Basic validation: each address should be in `IP:port` format (can add lightweight validation if needed)
