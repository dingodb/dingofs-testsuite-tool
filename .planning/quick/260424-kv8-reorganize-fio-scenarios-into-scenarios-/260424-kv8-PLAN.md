# Reorganize fio scenarios

## Problem

Current fio scenario structure is confusing:
- `/scenarios/fio/` — normal block size scenarios
- `/scenarios/fio_small/` — small block size scenarios

Better structure:
- `/scenarios/fio/bs_normal/` — normal block size scenarios (128K/1M/4M)
- `/scenarios/fio/bs_small/` — small block size scenarios (128B-8K)
