# Phase 11: 通知功能基础

## Plan 11-01: 添加 --wechat 和 --email 命令行参数及配置

**Objective:** 添加 --wechat 和 --email 命令行参数，并在 dtt config 中支持 webhook_url 和 email 设置

**Requirements Addressed:**
- NOTIFY-01: 添加 `--wechat` 命令行参数启用微信通知
- NOTIFY-02: 添加 `--email` 命令行参数启用邮件通知
- NOTIFY-03: 在 dtt config 中设置 webhook_url（微信）
- NOTIFY-04: 在 dtt config 中设置 email 地址
- NOTIFY-05: webhook_url 默认值使用配置中的值
- NOTIFY-06: email 默认发送到 daigy@zetyun.com

**Success Criteria:**
1. User can specify `--wechat` to enable WeChat notification
2. User can specify `--email` to enable Email notification
3. `dtt config set webhook_url <url>` stores WeChat webhook URL
4. `dtt config set email <address>` stores email address
5. Notifications use config values if set, otherwise use defaults

---

## Background

The current system:
- `dingofs-testsuite-tool` handles CLI and docker command building
- `entrypoint.sh` runs inside container and executes tests
- Config stored in `~/.dingofs_testsuite/` as individual files

We need to add:
- CLI flags `--wechat` and `--email` to enable notifications
- Config keys `webhook_url` and `email` to store notification settings

**Read first:**

**具体修改:**

1. 添加配置变量:

```bash
# Config files
WEBHOOK_URL_FILE="$CONFIG_DIR/webhook_url"
EMAIL_FILE="$CONFIG_DIR/email"

# Default webhook URL for WeChat
DEFAULT_WEBHOOK_URL="https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=9051ba90-dd37-4023-b49f-5db8ce78ac31"

# Default email
DEFAULT_EMAIL="daigy@zetyun.com"
```

2. 更新 `load_config()` 函数:

```bash
load_config() {
    local key="$1"
    case "$key" in
        testdir)
            [[ -f "$TESTDIR_FILE" ]] && cat "$TESTDIR_FILE" || echo ""
            ;;
        output)
            [[ -f "$OUTPUT_FILE" ]] && cat "$OUTPUT_FILE" || echo ""
            ;;
        image)
            [[ -f "$IMAGE_FILE" ]] && cat "$IMAGE_FILE" || echo "$DEFAULT_IMAGE"
            ;;
        mdsaddr)
            [[ -f "$MDSADDR_FILE" ]] && cat "$MDSADDR_FILE" || echo ""
            ;;
        webhook_url)
            [[ -f "$WEBHOOK_URL_FILE" ]] && cat "$WEBHOOK_URL_FILE" || echo "$DEFAULT_WEBHOOK_URL"
            ;;
        email)
            [[ -f "$EMAIL_FILE" ]] && cat "$EMAIL_FILE" || echo "$DEFAULT_EMAIL"
            ;;
    esac
}
```

3. 更新 `save_config()` 函数:

```bash
save_config() {
    local key="$1"
    local value="$2"
    case "$key" in
        testdir)
            echo "$value" > "$TESTDIR_FILE"
            ;;
        output)
            echo "$value" > "$OUTPUT_FILE"
            ;;
        image)
            echo "$value" > "$IMAGE_FILE"
            ;;
        mdsaddr)
            echo "$value" > "$MDSADDR_FILE"
            ;;
        webhook_url)
            echo "$value" > "$WEBHOOK_URL_FILE"
            ;;
        email)
            echo "$value" > "$EMAIL_FILE"
            ;;
    esac
}
```

4. 更新 `show_help()` 添加配置项:

```
  dtt config set webhook_url <url>  设置企业微信webhook地址
  dtt config set email <地址>      设置邮件通知地址 (默认: daigy@zetyun.com)
```

5. 更新 `cmd_config show` 显示配置:

```bash
config show)
    echo "Current Configuration:"
    local td=$(load_config testdir)
    local out=$(load_config output)
    local img=$(load_config image)
    local mds=$(load_config mdsaddr)
    local webhook=$(load_config webhook_url)
    local email=$(load_config email)
    echo "  testdir: ${td:-not set}"
    echo "  output:  ${out:-not set}"
    echo "  image:   ${img:-not set}"
    echo "  mdsaddr: ${mds:-not set}"
    echo "  webhook_url: ${webhook:-not set}"
    echo "  email: ${email:-not set}"
    ;;
```

6. 更新 `run_testsuite()` 添加 wechat 和 email flags:

```bash
    local wechat="" email_to=""

    while [[ $# -gt 0 ]]; do
        case "$1" in
            ...
            --wechat)
                wechat="yes"
                shift
                ;;
            --email)
                email_to="yes"
                shift
                ;;
            ...
        esac
    done
```

7. 在 docker command 构建部分添加环境变量传递:

```bash
    # Pass webhook_url if wechat notification enabled
    if [[ -n "$wechat" ]]; then
        local webhook_url=$(load_config webhook_url)
        docker_cmd+=("-e" "WECHAT=yes")
        docker_cmd+=("-e" "WEBHOOK_URL=$webhook_url")
    fi

    # Pass email if email notification enabled
    if [[ -n "$email_to" ]]; then
        local email_addr=$(load_config email)
        docker_cmd+=("-e" "EMAIL=yes")
        docker_cmd+=("-e" "EMAIL_TO=$email_addr")
    fi
```

### Acceptance Criteria
- `dtt config set webhook_url <url>` works
- `dtt config set email <addr>` works
- `dtt config show` displays webhook_url and email
- `--wechat` flag passes WECHAT=yes and WEBHOOK_URL to container
- `--email` flag passes EMAIL=yes and EMAIL_TO to container
