- Does NOT call log_result() or any notification functions
- Does NOT exit on error (handle missing files gracefully, set all counts to 0)

CRITICAL: The skip pattern `^not[[:space:]]+ok[[:space:]]+[0-9]+.*#.*TODO` MUST match lines containing "# TODO" (PJDTEST uses "# TODO" not "TODO" alone). **Function 1: `parse_ltp_output()`**

Signature: `parse_ltp_output()`
- Accepts two arguments: $1 = directory path to search for LTP output; $2 = ltp_exit code (for timeout detection)
- Uses `local raw_file=$(find "$1" -type f -name '*_smoketest.raw' 2>/dev/null | head -1)` to locate the raw output file
- If no file found, sets all counts to 0 and skips
- Counts using grep -cE with space-anchored patterns (space before marker prevents matching inside test names):
  - pass:  `grep -cE '[[:space:]]TPASS:' "$raw_file" 2>/dev/null || echo 0`
  - fail_tfail:  `grep -cE '[[:space:]]TFAIL:' "$raw_file" 2>/dev/null || echo 0`
  - fail_tbrok:  `grep -cE '[[:space:]]TBROK:' "$raw_file" 2>/dev/null || echo 0`
  - skip:  `grep -cE '[[:space:]]TCONF:' "$raw_file" 2>/dev/null || echo 0`
  - fail: sum of fail_tfail + fail_tbrok
- Sets global variables:
  - SMOKE_LTP_PASS
  - SMOKE_LTP_FAIL (TFAIL count + TBROK count)
  - SMOKE_LTP_SKIP (TCONF count)
  - SMOKE_LTP_TOTAL (pass + fail + skip)
- If $2 (ltp_exit code) is 124, sets SMOKE_LTP_TIMEOUT=1; otherwise sets SMOKE_LTP_TIMEOUT=0
- Echoes a one-line summary: "ltp stats: pass=X fail=Y skip=Z total=W [timeout=yes/no]"
- Does NOT exit on error, does NOT call log_result() or any notification functions
