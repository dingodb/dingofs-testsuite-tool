<task type="auto">
  <name>Task 1: Create Python report generation script</name>
  <files>scripts/generate_report.py</files>
  <action>
Create scripts/generate_report.py that:

1. Parses command-line arguments:
   - --tool (fio, vdbench, mdtest)
   - --output-dir (default: /data/results)
   
2. For fio JSON parsing:
   - Read $OUTPUT_DIR/fio.json (fio native JSON format)
   - Extract: job name, IOPS (read/write), bandwidth (read/write), latency (avg, min, max), CPU utilization, completion percentiles
   - Parse the nested 'jobs' array in fio JSON output

3. For vdbench text parsing:
   - Read $OUTPUT_DIR/vdbench.raw (or parse from vdbench output directory)
   - Extract: throughput, IOPS, response time from standard vdbench output format
   - vdbench typically outputs "avg_2" response time and transaction rates

4. For mdtest text parsing:
   - Read $OUTPUT_DIR/mdtest.raw
   - Extract: items/sec (create/delete rates), tree operations, timing info

5. Generate HTML report (report.html):
   - Single HTML file with embedded CSS and JS (no external dependencies)
   - Include performance metrics tables for each tool
   - Add bar charts using Chart.js (CDN or inline) for IOPS/throughput comparison
   - Show test configuration summary at top
   - Responsive design, professional styling

6. Generate text summary (summary.txt):
   - Header with test timestamp and tool name
   - Section: Test Configuration (tool, scenario, mount point)
   - Section: Key Performance Metrics (IOPS, throughput, latency)
   - Section: Raw Output Reference (which files contain full output)
   - Complete information per D-24

7. Output files to $OUTPUT_DIR:
   - report.html
   - summary.txt

Use Python standard library only (json, argparse, datetime, html escape) to minimize dependencies.
  </action>
