<task type="auto">
  <name>Task 2: Implement mode handling</name>
  <files>entrypoint.sh</files>
  <action>
Add mode handling to entrypoint.sh:

**run_one_shot() function (MODE-01):**
- Execute the test tool with appropriate parameters
- Wait for completion
- Exit with tool's exit code
- Container exits after test (normal Docker behavior)

**run_long_running() function (MODE-02, MODE-03):**
- Execute the test tool with appropriate parameters
- Wait for completion
- After test completes, enter long-running state:
  - Print "Test completed. Container staying alive for additional tests."
  - Print "To run additional tests: docker exec <container> entrypoint.sh -t fio -s rand_read"
  - Use `tail -f /dev/null` or similar to keep container alive
- Handle SIGTERM gracefully for docker stop
- Listen for docker exec commands and run them

**Entrypoint logic:**
```bash
if [ "$MODE" = "long-running" ]; then
    # First run: execute test then stay alive
    run_one_shot
    # After test, enter long-running mode
    run_long_running
else
    # One-shot mode: just run test and exit
    run_one_shot
fi
```
