<task type="auto">
  <name>Task 2: Update Dockerfile with entrypoint</name>
  <files>Dockerfile</files>
  <action>
Update Dockerfile to add entrypoint.sh:

After the scenario COPY instruction, add:
```dockerfile
# Phase 2: Copy and set entrypoint
COPY entrypoint.sh /entrypoint.sh
RUN chmod +x /entrypoint.sh
ENTRYPOINT ["/entrypoint.sh"]
```

**Important:** Remove or comment out the existing `CMD ["/bin/bash"]` line since ENTRYPOINT now handles the default behavior. The ENTRYPOINT directive makes entrypoint.sh the default command, but users can still override with `docker run <image> /bin/bash` if needed.

Alternative approach using exec form to ensure signals are properly handled:
```dockerfile
ENTRYPOINT ["/bin/bash", "/entrypoint.sh"]
```

This ensures bash handles the script execution properly.
