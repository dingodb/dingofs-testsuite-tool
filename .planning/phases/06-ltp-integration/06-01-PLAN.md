# LTP Integration Details

## Current Tools in entrypoint.sh
- fio → fio_run()
- vdbench → vdbench_run()
- mdtest → mdtest_run()
- pjdtest → pjdtest_run()

## Required Changes

1. Add `ltp` to validate_params() tool regex:
   - Current: `^(fio|vdbench|mdtest|pjdtest)$`
   - New: `^(fio|vdbench|mdtest|pjdtest|ltp)$`

2. Add `ltp` case to dispatch_tool():
   ```bash
   ltp)
       ltp_run
       ;;
   ```

3. Add ltp_run() function:
   ```bash
   ltp_run() {
       echo "Running LTP test suite"
       echo "  Mount: $MOUNT"
       echo "  Output: $OUTPUT"
       echo "  Scenario: $SCENARIO"

       mkdir -p "$OUTPUT"

       cd "$MOUNT"

       local timestamp
       timestamp=$(date +"%Y%m%d_%H%M%S")
       local output_file="${OUTPUT}/ltp_${timestamp}"

       # Default to filesystem tests (-f fs)
       local scenario="${SCENARIO:-fs}"

       # Run LTP with timeout protection
       timeout 3600 /opt/ltp/runltp -p "$OUTPUT" -l "${output_file}.log" -d "$MOUNT" -f "$scenario"

       return $?
   }
   ```

4. Update help text to include ltp tool

## Important Notes

- runltp is deprecated in favor of kirk, but still works
- LTP tests require --privileged or specific capabilities for full functionality
- timeout 3600 prevents indefinite hanging (1 hour max)
- Output goes to: $OUTPUT/ltp_<timestamp>.log
</context>
