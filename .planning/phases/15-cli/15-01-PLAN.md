```bash
show_mlperf_help() {
    cat << 'EOF'
MLPerf Storage 基准测试
======================

MLPerf Storage 是 MLPerf 组织定义的存储性能基准测试套件，用于评估存储系统在机器学习工作负载下的性能表现。

用法:
  dtt -t mlperf [-s <场景>] [--scale <规模>] [--file_count <数量>] [--gpu_count <数量>]

参数:
  -s, --scenario <名称>
      测试场景，可选值:
        resnet50       - ResNet-50 图像分类模型
        unet3d         - 3D U-Net 医学图像分割模型
        cosmoflow      - CosmoFlow 宇宙学模拟模型
        checkpointing  - 检查点读写测试
        all            - 运行所有场景 (默认值)

  --scale <规模>
      测试数据集规模，控制生成的文件数量、文件大小和训练轮数:
        small  - 小型数据集: 32 files, 5 epochs (默认值)
        medium - 中型数据集: 256 files, 10 epochs
        large  - 大型数据集: 1024 files, 20 epochs

  --file_count <数量>
      自定义生成测试文件数量 (正整数)
      注意: 同时指定 --scale 和 --file_count 时，--file_count 优先级更高
      不同 scale 对应的默认 file_count:
        small=32, medium=256, large=1024

  --gpu_count <数量>
      并发 GPU 数量，用于模拟多 GPU 训练场景
      默认值: 1

  --help, -h
      显示此帮助信息

示例:
  # 运行所有场景 (默认 small 规模, 1 GPU)
  dtt -t mlperf -s all

  # 运行单个场景
  dtt -t mlperf -s resnet50

  # 中型规模测试, 4 GPU
  dtt -t mlperf -s unet3d --scale medium --gpu_count 4

  # 自定义 500 个文件 (覆盖 --scale 的默认值)
  dtt -t mlperf -s all --file_count 500

  # 小规模快速验证
  dtt -t mlperf -s checkpointing --scale small

注意:
  - mlperf 使用独立的 mlperf-storage 容器，不依赖 dtt 主镜像
  - 测试数据写入 dtt config testdir 配置的目录
  - 测试结果保存到 dtt config output 配置的目录

更多信息:
  - MLPerf Storage: https://github.com/mlcommons/storage
EOF
}
```

The heredoc delimiter must be `'EOF'` (quoted) so that bash does not expand `$` signs in the help text.
